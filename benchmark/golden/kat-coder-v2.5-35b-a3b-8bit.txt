A mutex, short for mutual exclusion, is a synchronization primitive used to protect shared resources from being accessed by multiple threads simultaneously. It ensures that only one thread can access a critical section of code at a time, preventing race conditions and ensuring data consistency. You would use a mutex when multiple threads need to access and modify shared data, and you want to ensure that only one thread can modify the data at any given moment.
